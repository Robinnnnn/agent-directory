# Agent Directory

A clean, customizable agent roster UI built with React + Vite.

## What this is

This project is a public template for displaying a directory of AI agents:
- compact list / card views
- per-agent metadata (role, model, schedules)
- Q&A panel
- mobile-friendly interactions

## Quick start

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Data model

The UI is driven by `public/agents.json`.

Use it as sample data and replace with your own safe/public values.

## Customize

- `src/components/*` → layout and UI behavior
- `src/style.css` → visual system and effects
- `public/agents.json` → your roster content

## Deploy

This is a static Vite app and can be deployed to Cloudflare Pages, Vercel, Netlify, or any static host.
